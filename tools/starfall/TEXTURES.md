# Starfall Isle textures

Photo-scanned surfaces come from [Poly Haven](https://polyhaven.com) and are **CC0** (public domain —
free for any use, no attribution required). They were downloaded with `curl` from the Poly Haven API,
resized and saved as WebP into `public/games/starfall/textures/`:

| Game texture | Poly Haven asset | Notes |
| --- | --- | --- |
| grass_albedo / grass_normal | `leafy_grass` (2k) | albedo colour-graded to lush summer green (luminance kept) |
| sand_* | `coast_sand_01` (2k) | |
| dirt_* | `rocks_ground_02` (2k) | used for paths |
| rock_* | `rock_face_03` (2k) | cliffs, triplanar |
| planks_* | `weathered_brown_planks` (1k) | |
| stone_* | `medieval_blocks_03` (1k) | |
| bark_* | `bark_brown_02` (1k) | |
| roof_* | `clay_roof_tiles_02` (1k) | |
| plaster_albedo | `white_rough_plaster` (1k) | |

Everything else (cloth, leaves atlas, water normal, noise, clouds, glow) is generated by
`gen_textures.py`. To regenerate only those without overwriting the scans:

    python3 tools/starfall/gen_textures.py --only cloth,leaves,water_normal,noise,clouds,glow
