Python
Runtime for Frida scripts and automation. Install 3.11+ from python.org — always check "Add to PATH" on Windows.
python.org →
⚡
Frida
Dynamic instrumentation. Hook functions, intercept calls, read/write memory — all from JavaScript inside the running process.
frida.re →
🔍
Cheat Engine
Memory scanner and debugger. Find addresses for health, speed, ammo. Works alongside Frida scripts.
cheatengine.org →
🔬
x64dbg
Open-source x64/x32 debugger for Windows. Essential for understanding game code flow and finding hook points.
x64dbg.com →
📦
dnSpy
Decompiler and debugger for .NET games (Unity C#). Read and modify compiled game assemblies.
GitHub →
🎮
BepInEx
Unity game patcher and plugin framework. The standard way to load mods into Unity-based games.
